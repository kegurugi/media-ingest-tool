mit Field Card

Media Ingest Tool · card offload, verify and logs

New New show

mit init ~/Documents/PARA/Projects/ShowName/ingest

Answers questions and writes project.json. New season: add --from and the last show's folder. Check a show with mit config.

Start Each morning

Open Terminal and go into the show's folder (the one with project.json). Type cd , drag the folder in from Finder, press Return.

cd ~/Documents/PARA/Projects/ShowName/ingest

Every mit command after that uses this show's settings. Check where you are with pwd.

Card Offload a card

mit ingest
  1. Source card pathdrag the card in, e.g. /Volumes/Untitled
  2. DestinationsReturn for the defaults
  3. Camera IDe.g. A, DR1
  4. Shoot date [10132026]Return. If clips cross midnight it asks you to type the shoot day.
  5. Use these for 10/13/2026?First card of a day only. Return keeps; n edits each field (Return keeps · type replaces · - removes).
  6. Is this the same card? Recopy it as …Only after a failed or interrupted copy. y recopies under the same name.
  7. Card name ABC261013A01Return; n lets you type a reel number
  8. Media type [VIDEO]Return. A red box means check before overriding.
  9. Notes for this carde.g. "card ejected mid-clip 0032", or Return
  10. Start offload?y

Result What the end means

PASSEvery file verified on every drive. The summary lists each drive's free space.
FAIL (red box)Don't reuse the card. Run mit ingest again and answer y to recopy it.
Interrupted (Ctrl-C, cable)Nothing lost. Run mit ingest again; it offers to recopy under the same name.
warning: linesThe media is safe; something else (log, report) needs a rerun. The warning names the command.

Before a card goes back to camera: it must show PASS, and the wrap check below must pass on both drives.

Wrap End of day

Re-check today's cards on each drive (reads every byte again):

mit verify --drive DRV01A --date 10132026 mit verify --drive DRV01B --date 10132026

Add or change the day's notes, header fields or crew:

mit daylog 10132026

Proxies, only if post needs them: mit proxies --drive DRV01A --date 10132026

Ship Shuttle drive arrives

mit verify --drive DRV01B

Checks every card the drive's log lists. A missing card folder is a FAIL. Exit status 0 = all passed.

Fix If something's off

You seeDo
"same physical disk"Use two separate drives. Partitions of one drive don't count.
"Not enough free space"Nothing was copied. Swap in a drive with room.
"Destinations disagree about … reels"Stop. The drives don't match; check for a half-copied card.
Master log not updated / damagedmit log rebuild
Report or day log needs refreshingmit report 10132026
New laptop, project totals gonemit history rebuild --dest DRV01A --dest DRV02A
Older card has no ASC MHLmit mhl --drive DRV01A
Spreadsheet out of datemit log export
